# Routes Directory

This directory will store your Express route handlers to keep `server.js` clean and modular.

### Planned Route Modules:
- **`authRoutes.js`**: Endpoints for `/api/auth/register`, `/api/auth/login`, and `/api/auth/me`.
- **`productRoutes.js`**: Endpoints for `/api/products` (list, search, detail, create, update, delete).
- **`cartRoutes.js`**: Endpoints for `/api/cart` (view items, add item, update quantity, remove item).
- **`orderRoutes.js`**: Endpoints for `/api/orders` (place order, user orders, admin order management).
