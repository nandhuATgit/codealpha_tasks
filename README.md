# CodeAlpha Tasks

## Task 1 - E-Commerce Store

### Technologies
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB

### How to Run

1. Open the Task-1-Ecommerce-Store folder.

2. Install dependencies:

npm install

3. Create a `.env` file using `.env.example`.

4. Add the required MongoDB connection string and other environment variables.

5. Start the server:

node server.js

6. Open:

http://localhost:5000
